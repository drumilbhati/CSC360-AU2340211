# Reflection — 20 August 2026

## Topic: Creating and Structuring a Markdown File

In this class, I learned how to create a Markdown file and organize its content clearly.

## Recommended structure

A well-structured reflection should include:

1. **Heading or title** — Identifies the class date or main subject.
2. **Topics discussed** — Lists the concepts covered during the class.
3. **Brief discussion of each topic** — Explains the important points in enough detail to demonstrate understanding.
4. **Personal notes and reflection** — Records observations, lessons learned, questions, and possible applications.

## Content guidelines

When writing and organizing the content:

- Be specific rather than general.
- Use clear headings and subheadings.
- Keep related information together.
- Use lists when presenting steps or multiple points.
- Explain each topic briefly and clearly.
- Avoid repeating the same information.
- Keep the formatting consistent throughout the document.

## Key takeaway

A Markdown reflection should be easy to scan while still providing enough detail to explain what was learned. A clear structure makes the content easier to understand, review, and maintain.
